Find and Understand a 404 Page

Goal: Understand what happens when a visitor goes to a URL that doesn't exist on your site.
  1. 1. Visit your GitHub Pages site URL with a path that doesn't exist:
  2. https://roziboyahmadaliyev1310-sy.github.io/web-programming/week10/this-does-not-exist.html
  3. 2. This repository has a custom 404.html in its published root, so the live site should show the custom page rather than GitHub's generic 404.
  4. 3. Note what the page looks like. Is this a good user experience? What would you improve?
  5. 4. GitHub Pages uses the 404.html file at the published root for missing pages across the site. This project's custom site-wide page is in the repository root.
💡

GitHub Pages automatically serves 404.html when a page isn't found — if that file exists in your repo. If it doesn't exist, GitHub shows its generic error page. Exercise 3 fixes this!
