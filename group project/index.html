One travel toolkit

From first idea to trip details.

The project homepage introduces destinations and connects travelers to four focused tools for planning and preparing a journey.

01 / PLAN

Trip planner

Search for a city or country, explore nearby places, and shape a seven-day itinerary.

02 / WEATHER

Weather guide

Check local conditions and a five-day forecast to help decide what to pack.

03 / BUDGET

Currency converter

Convert fiat and crypto currencies and compare costs in local money.

04 / DISCOVER

Media library

Search for films and books that add a little context and inspiration to a trip.

How to use it

A simple travel-planning flow.

01. Pick a place

Browse featured destinations or search for a city or country that interests you.

02. Build an outline

Use the trip planner to find nearby attractions and organize a week of ideas.

03. Get prepared

Check the forecast, estimate currency costs, and find books or films about the destination.

Project notes

Built for the browser.

Technology

HTML · CSS · Vanilla JavaScript · ES modules

The apps use public data services for weather, destinations, books, movies, and exchange rates. Some services need an API key; details are in the project README.

Run the project

Because the tools use JavaScript modules, serve the repository over HTTP rather than opening the files directly. The README in the app folder has setup notes.
