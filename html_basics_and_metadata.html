Module 1: Fundamentals & Invisible Metadata

1. What is HTML?

HTML (HyperText Markup Language) describes the structure of a web page using tags. It is not a programming language—it cannot make calculations or decisions. Every web page starts with an HTML file.

2. DOCTYPE & Page Structure

The <!DOCTYPE html> declaration must be the first line to trigger standards mode in modern browsers, preventing unpredictable "quirks mode" rendering.

The <body> tag contains everything visible to the user, while <head> holds invisible metadata.

3. Essential Head Metadata

  • <meta charset="UTF-8"> — Must be first in <head> to decode all human languages (including Korean 한글) and emojis without rendering garbage text.
  • <title> — Sets browser tab text and Google search headline (does NOT appear on the page body).
  • lang="en" attribute — Declares language for accessibility screen readers and translation tools; omitting it causes WCAG violations.
