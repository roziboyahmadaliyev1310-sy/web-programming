Lesson 7

Summary and assignment

Keep these core ideas close while building your own data-driven page.

fetch(url)

Sends an HTTP request and immediately returns a Promise.

response.json()

Reads and parses the response body as JSON; it also returns a Promise.

response.ok

Is true for successful HTTP status codes. Check it because a 404 does not automatically reject fetch.

async / await

Lets you write Promise-based work in a clear, sequential style without freezing the page.

try / catch

Handle network, parsing, and explicitly thrown HTTP errors.

finally

Runs after success or failure. Use it to reset buttons and stop loading indicators.
