Promises and async/await

The async/await syntax makes network code easier to read and write.

Async functions let JavaScript pause a function without freezing the whole page. This is why await works so well with fetch().

async function loadData() {
  const response = await fetch('https://jsonplaceholder.typicode.com/todos/1');
  const data = await response.json();
  console.log(data);
}
Important: await pauses only this function, not the entire browser app.

Promise states

  • Pending: waiting for the result
  • Fulfilled: data arrived successfully
  • Rejected: something went wrong
A Promise is like a ticket: you ask for something, and later you receive the result.
