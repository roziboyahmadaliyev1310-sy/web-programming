The request journey

Follow what happens after JavaScript asks a server for data.

A network request happens in the background. Your page remains available while the browser communicates with the server.

1 · BrowserSends a request with fetch().
2 · InternetCarries the request to the server.
3 · ServerFinds and returns a response.
4 · PageJavaScript reads data and updates the DOM.

Select play to follow a request.

Analogy: ordering food at a busy restaurant. You place the order, keep talking with friends while it is prepared, and receive the food when it is ready.
