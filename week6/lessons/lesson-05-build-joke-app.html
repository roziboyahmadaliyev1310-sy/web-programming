Lesson 5

Build the joke app step by step

A small example combining HTML, fetch(), async/await, and error handling.

Expand each step to see how the app grows. The complete working version is in Random Joke Fetcher practice.

Step 1 · Add the page elements

Start with a button, a status message, and an empty area for the response.

<button id="load-button">Load a joke</button>
<p id="status"></p>
<div id="joke"></div>
Step 2 · Show that work is happening

Update the status before making the request so the page does not look unresponsive.

async function loadJoke() {
  status.textContent = 'Loading…';
}
Step 3 · Request the data and parse JSON

The response and its JSON body are separate asynchronous results, so await both.

const response = await fetch(
  'https://official-joke-api.appspot.com/random_joke'
);
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const joke = await response.json();
Step 4 · Render the result safely

Use textContent for text returned by an API instead of inserting untrusted strings as HTML.

jokeArea.textContent = `${joke.setup} — ${joke.punchline}`;
status.textContent = 'Joke loaded';
Step 5 · Handle errors and always finish loading

Use catch to report failure and finally to restore the button after either outcome.

try {
  // fetch, check response.ok, parse JSON, and render
} catch (error) {
  status.textContent = `Could not load a joke: ${error.message}`;
} finally {
  loadButton.disabled = false;
}
