What is fetch()?

The browser sends a request to a server and waits for data without reloading the page.

fetch() is JavaScript's built-in way to request data from an API or server. It returns a Promise, which means the browser keeps working while the request finishes in the background.

fetch('https://official-joke-api.appspot.com/random_joke')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error(error));
Key idea: your page stays interactive while waiting. The request happens asynchronously.

Request journey

  • Browser sends a request
  • Server finds the data
  • Data comes back as JSON
  • JavaScript updates the page
Result: the page can show updates without full reloads. This is one of the foundations of modern web apps.
