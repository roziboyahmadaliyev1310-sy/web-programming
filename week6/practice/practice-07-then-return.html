Return values in .then()

A Promise chain passes each callback’s return value to the next callback.

fetch(url)
  .then(response => {
    response.json();
  })
  .then(data => render(data));
The first callback does not return response.json(). What does the next .then() receive?

Show the corrected chain 
fetch(url)
  .then(response => {
    return response.json();
  })
  .then(data => render(data));

Returning the Promise from response.json() lets the next .then() receive its parsed value.
