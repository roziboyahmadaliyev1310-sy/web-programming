Follow a request

Put the browser, server, and page updates in context while a fetch request runs.

1 · Browserfetch(url) sends a request.
2 · ServerThe server finds and returns a response.
3 · JavaScriptresponse.json() reads the data.
4 · PageYour code updates the page with the data.

Press play to follow the request.

Think about it: Does the page have to reload when the request returns? No—JavaScript can update just the relevant part of the page.
