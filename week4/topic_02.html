Selecting Elements

Beginner

Before you can change anything on the page, you need to select it. JavaScript has several ways to grab elements from the DOM.

The oldest (but still used) method is getElementById() — it finds one element by its id attribute. It returns the element object, or null if nothing matches.

JavaScript
// Grab the element with id="greeting" const heading = document.getElementById('greeting'); // Now 'heading' is the actual DOM element — you can change it heading.textContent = 'Hello, class!'; heading.style.color = 'blue';

Key Points

  • getElementById('id') returns one element (or null).
  • The returned object has properties: .textContent, .style, .classList, etc.
  • IDs must be unique on the page — each getElementById call finds at most one element.
