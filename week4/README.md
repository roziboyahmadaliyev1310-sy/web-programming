# Week 4 DOM Events

This folder contains the Week 4 JavaScript DOM and Events lessons and activities. Each lesson focuses on a visible, interactive result; every page is self-contained with inline styles and scripts.

## Open the page

Open `index.html` in a browser to view the catalog. The individual lesson examples and practice activities are in `lessons/` and `practice/`.

## Files

- `index.html` — lesson and practice catalog
- `lessons/` — 12 topic-specific interactive demos
- `practice/` — 4 standalone interactive exercises
