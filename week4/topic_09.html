09

e.preventDefault()

Intermediate

Some elements have built-in default browser behavior: a form submits and reloads the page, a link navigates to a URL, right-click opens a context menu. e.preventDefault() stops the browser's default action so your JavaScript can handle it instead.

JavaScript
const form = document.querySelector('#login-form'); form.addEventListener('submit', (e) => { e.preventDefault(); // ← stops the page reload! // Now validate and handle the form with JavaScript const email = document.querySelector('#email').value; if (!email.includes('@')) { showError('Please enter a valid email.'); } else { loginUser(email); } });
❌ Without preventDefault
✅ With preventDefault

Key Points

  • e.preventDefault() stops the browser's default action.
  • Use on forms ('submit') to handle validation without page reload.
  • Use on links ('click') to prevent navigation.
  • Call it as the first line of your handler so the default never fires.
