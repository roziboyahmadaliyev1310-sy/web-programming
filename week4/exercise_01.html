E1

Click Counter with Color Change

Beginner
Task: Make the button below count clicks. After 5 clicks, change the button color to green and show a congratulations message.
  • Select the button with querySelector
  • Add a 'click' event listener
  • Update the counter text with textContent
  • At 5 clicks: use classList.add('done') and update message
Hint: Use let count = 0; outside the listener so it persists between clicks. Inside the listener: count++; then countEl.textContent = count; Then check if (count >= 5) { btn.classList.add('done'); ... }
Solution
const btn = document.querySelector('#clicker'); const countEl = document.querySelector('#count'); const msg = document.querySelector('#message'); let count = 0; btn.addEventListener('click', () => { count++; countEl.textContent = count; if (count >= 5) { btn.classList.add('done'); msg.textContent = '🎉 Congratulations! You clicked 5 times!'; } });
