E2

Dark Mode Toggle Card

Beginner
Task: Build a profile card with a dark mode toggle button. Clicking the button should toggle a dark class on the card.
  • Select the card and the toggle button
  • Add a click listener to the button
  • Use classList.toggle('dark') to switch modes
  • Update the button text based on classList.contains('dark')
Hint: After card.classList.toggle('dark'), check card.classList.contains('dark') to set the right button text. If it's dark, show "☀️ Light Mode", otherwise "🌙 Dark Mode".
Solution
const card = document.querySelector('#card'); const btn = document.querySelector('#toggle-btn'); btn.addEventListener('click', () => { card.classList.toggle('dark'); if (card.classList.contains('dark')) { btn.textContent = '☀️ Light Mode'; } else { btn.textContent = '🌙 Dark Mode'; } });
