Removing Elements

Beginner

Elements can be removed from the DOM with .remove() — the simplest modern method. The element simply disappears from the page.

JavaScript
// Select and remove an element const item = document.querySelector('.to-delete'); item.remove(); // gone! // Remove when a delete button is clicked (inside list item) const list = document.querySelector('#my-list'); list.addEventListener('click', (e) => { if (e.target.matches('.delete-btn')) { e.target.closest('li').remove(); // remove the parent li } });

Demo — Click × to remove items

Key Points

  • element.remove() — removes the element from the DOM.
  • e.target.closest('li') — finds the nearest ancestor matching a selector (useful in delegation).
  • Removed elements can still be held in JS variables and re-added later.
