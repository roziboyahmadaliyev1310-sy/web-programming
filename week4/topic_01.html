What is the DOM?

Beginner

When a browser loads an HTML file, it reads it and builds a tree of objects in memory. This tree is called the DOM — Document Object Model. Every HTML tag becomes a node (an object) in the tree, and JavaScript can read and change any node.

Think of the DOM as a living map of the page. You write HTML once; the DOM lets JavaScript update the page at any time — without reloading.

Visual — The DOM Tree

This HTML file becomes this tree in memory:

HTML file
<html> <head> <title>My Page</title> </head> <body> <h1 id="title">Hello</h1> <p>World</p> </body> </html>
DOM Tree in memory
document └── html ├── head │ └── title "My Page" └── body ├── h1 id="title" │ └── "Hello" └── p └── "World"
✅
JavaScript uses document (the root object) to access any part of this tree. Change a node → the page updates instantly.

Key Points

  • DOM = Document Object Model — the browser's in-memory tree of the page.
  • Every HTML tag becomes a node (object) JavaScript can access.
  • document is the root — the starting point for all DOM access.
  • Changing the DOM updates the page without reloading.
